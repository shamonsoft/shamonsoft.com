About ShamonSoft

One developer. A growing collection of creative tools.

ShamonSoft is an independent software studio built around a simple idea: creative software should be interesting to use without becoming a chore to own. The focus is visual software, experimentation, practical tools and a clean experience from installation onward.

Development combines hands on design, testing, iteration and AI assisted coding. The end goal is always the same: software that feels polished, useful and trustworthy.
